# 차단 페이지와 입원 기록

차단 화면은 `web/blocked.html`이다. 사용자 지정 용어를 다음과 같이 사용한다.

| 보안 의미 | 화면 표현 |
| --- | --- |
| 격리 | 입원 |
| 샌드박스 | 폐쇄적 환경 |
| 추가 격리 | 안정실 |
| 공격 위험성 | 공격 위험성 |

화면은 웹 요청의 차단을 표현한다. 서버 안의 모든 PHP worker가 별도 파일·네트워크 namespace에 들어갔다는 증명은 아니다. 실제 격리 경계는 활성 정책과 검증 결과로 판단한다.

네이티브 확장에 `phese.block_page=/absolute/root-controlled/blocked.html`을 시스템 설정으로 지정하면 시작 시 파일을 읽어 보관한다. `{{EVENT_ID}}`와 `{{TIMESTAMP}}`는 차단 시 생성한 기록 번호와 UTC 시각으로 치환한다. 상세 함수명, PHP 인자, 파일 경로와 요청 본문은 페이지에 표시하지 않는다. 이 파일을 바꾸면 해당 PHP 서비스를 재시작해야 한다.

외부 프로세스 실행 등 PHP 수준의 명시적 차단 대상 함수 호출은 웹 SAPI에서 실행 전에 차단 응답을 생성한다. 낮은 수준의 임의 시스템 호출은 seccomp가 차단하지만, 모든 EPERM을 HTTP 차단 페이지와 연결하거나 로그로 포착한다고 주장하지 않는다. 기존 `disable_functions`로 함수가 이미 제거된 경로도 네이티브 함수 훅을 거치지 않을 수 있다.

로그의 실제 문제는 `reason`과 필요시 허용목록의 `function`으로 남긴다. 요청한 문구 `ㅋㅋㅋㅋㅋ어떻게병동이름이폐쇄얔ㅋㅋㅋㅋㅋㅋ`는 입원 이벤트의 `message`에 기록한다. 로그 보관과 회전은 [로그 안내](logging.md)에 설명한다.
